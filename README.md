# EBank

Console login-validation exercise with English and Vietnamese messages.

## Requirements

- JDK 17 or newer

## Run

From the project directory:

```bash
./mvnw compile exec:java
```

On Windows, use `mvnw.cmd compile exec:java`.

Choose `1` for Vietnamese, `2` for English, or `3` to exit.

## Build

```bash
./mvnw clean package
```

The compiled application is written under `target/`.
